# Разметка кадров в Label Studio

Кадры уже выбраны программой (`data/frames/`, 340 штук из 4 видео).
Размечаем одну метку — **доска** (контур). Людей не размечаем.

Разметка идёт **в два круга**:
- **Круг 1 — 80 кадров** (`labeling/tasks_round1.json`). Размечаете вручную.
  На этих кадрах обучится черновая модель.
- **Круг 2 — 260 кадров** (`labeling/tasks_round2.json`). Их сначала разметит
  черновая модель, вы только проверяете и поправляете.

## 1. Установка Label Studio (один раз)

В PowerShell:

```powershell
cd путь\к\проекту\machine_learning
py -3.12 -m venv .venv-ls
.venv-ls\Scripts\python.exe -m pip install label-studio
```

## 2. Запуск (каждый раз)

```powershell
cd путь\к\проекту\machine_learning
$env:LABEL_STUDIO_LOCAL_FILES_SERVING_ENABLED = "true"
$env:LABEL_STUDIO_LOCAL_FILES_DOCUMENT_ROOT = "$PWD\data"
.venv-ls\Scripts\label-studio.exe start
```

Откроется браузер (http://localhost:8080). Первый раз — зарегистрируйтесь
(любой e-mail и пароль, всё хранится только на вашем компьютере).
Окно PowerShell не закрывайте, пока размечаете.

## 3. Создание проекта (один раз)

1. **Create Project** → имя `Доски`.
2. Вкладка **Labeling Setup** → **Custom template** → вставьте содержимое файла
   `labeling/label_config.xml` → **Save**.
3. В проекте: **Settings** → **Cloud Storage** → **Add Source Storage**:
   - Storage Type: **Local files**
   - Absolute local path:
     `путь\к\проекту\machine_learning\data\frames`
   - **Add Storage**. Кнопку **Sync** НЕ нажимайте.
4. В проекте: **Import** → файл `labeling/tasks_round1.json` → **Import**.

Должно появиться 80 заданий. Если вместо картинки ошибка загрузки — проверьте,
что Label Studio запущен командами из шага 2 (с двумя строками `$env:...`).

## 4. Как размечать

Откройте задание. В некоторых кадрах уже есть черновой зелёный контур
(вкладка **Predictions**) — он часто неточный: исправьте или удалите его.
Пропущенные доски дорисуйте. Нажмите **Submit** — откроется следующий кадр.

### Что обводить
- **Каждую доску на конвейере**, в том числе ту, которую кладут наискосок
  или которая видна частично.
- Доска уходит за край кадра или в станок — обводите **до края кадра**.
- Доска частично закрыта рукой или рабочим:
  - **закрыт торец** (конец доски под рукой) — контур **до руки**, конец не угадываем;
  - **рука поперёк середины доски**, с обеих сторон доска видна — **один контур
    через руку**, по всей доске (никогда не два контура на одну доску);
  - рука чуть заходит на край доски сбоку — не обращайте внимания, ровный край.
- **Одна доска — один контур.** Две доски рядом — **два отдельных контура**.
- Контур — это **4 угла доски** (по 2 на каждом торце), соединённые **вдоль краёв
  доски** с её наклоном (не рамка «по осям»). Поэтому контуры соседних досок
  не пересекаются; если доски касаются — контуры идут по общей границе.
- Одна доска лежит поверх другой: верхнюю — целиком, нижнюю — по видимой части;
  если верхняя лежит поперёк нижней и нижняя видна с обеих сторон — нижняя
  одним контуром через верхнюю (наложение контуров допустимо).
- Доска не видна целиком — контур всё равно **замкнутый**: по краю кадра,
  по границе рабочего или там, где доска уходит в станок.
- Доска у края кадра сужается и изгибается («рыбий глаз») — ставьте точки
  там, где реально проходят её края; если прямая между точками заметно отходит
  от края доски — добавьте точку посередине.
- Короткий обрезок на конвейере — тоже «доска».

### Доску несут или берут из пачки
- Доска **хотя бы частично над конвейером** (над роликами), лежит или её держат —
  **обводите всю доску одним контуром**, включая часть над пачкой; если не видно,
  где она кончается среди досок пачки, — до места, где её ещё уверенно видно.
- Доска **целиком вне конвейера** (несут в руках рядом, лежит на полу, в пачке) —
  **не обводите**.

### Что НЕ обводить
Пачки досок сбоку от конвейера, лестницу, планку-маркер, доски на полу,
тени и отблески.

### Пустой кадр
Нет досок на конвейере — просто **Submit** без разметки.
Такие кадры тоже нужны: модель учится, что «здесь доски нет».

### Как рисовать контур
- Клавиша **1** (или щелчок по метке `доска`) → щёлкайте по углам доски →
  замкните контур щелчком по первой точке. Для прямой доски хватает 4 точек,
  у края кадра доска изогнута — добавьте 1–2 точки посередине длинных сторон.
- Подвинуть точку — перетащить мышью. Добавить точку — щелчок по линии контура.
- Удалить контур: выделите его → **Backspace**.
- Приближение — колесо мыши.

Точность «до пикселя» не нужна. Главное — **аккуратно обвести торцы**:
по ним меряется длина.

## 5. Когда закончите круг 1

**Export** → формат **JSON** → сохраните как
`machine_learning/labeling/export_round1.json` и напишите мне.
Дальше я обучу черновую модель и подготовлю круг 2.

Можно размечать частями: Label Studio всё сохраняет.
