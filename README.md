# Подсчёт досок и коротких досок (нейросеть + OpenCV)

Программа `measure_boards.py` берёт **одно видео** с камеры над конвейером и выдаёт:

- сколько досок проехало в станок;
- сколько из них **выбросов** — короче нормы N на 10% и более;
- длину каждой доски в сантиметрах (таблица `boards.csv`);
- по желанию — видео с разметкой, чтобы глазами проверить работу.

Внутри две части:
- **нейросеть** (YOLO, обучена на кадрах с этой камеры) находит доски;
- **OpenCV** читает видео, следит за движением доски и переводит пиксели в сантиметры.

## 1. Установка (один раз)

Нужен **Python 3.12** (python.org, при установке отметить «Add python.exe to PATH»).
Все команды — в PowerShell, из папки `machine_learning`:

```powershell
cd путь\к\проекту\machine_learning
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
```

Дальше — **один из двух вариантов**, в зависимости от того, на чём считать нейросеть.

### Вариант А — процессор (подходит любому компьютеру)

```powershell
.venv\Scripts\python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### Вариант Б — видеокарта NVIDIA (быстрее)

1. Свежий драйвер NVIDIA. Проверка: команда `nvidia-smi`, в таблице `CUDA Version` должна быть
   **12.8 или выше** (для RTX 50-й серии — драйвер 570 или новее).
2. PyTorch **с поддержкой видеокарты** — именно по этой ссылке (обычный `pip install torch`
   поставит вариант без видеокарты):

```powershell
.venv\Scripts\python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

3. Проверка, что видеокарта видна:

```powershell
.venv\Scripts\python.exe -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

Должно быть `True` и название видеокарты.

Программа сама выбирает, на чём считать (`device = "auto"` в `config.toml`): есть видеокарта
NVIDIA, которую видит PyTorch, — на ней, иначе на процессоре. Переключить вручную — параметр
`--device cpu` или `--device 0` при запуске.

### Проверка установки

```powershell
.venv\Scripts\python.exe settings.py
```

Покажет настройки и строку `Нейросеть на: процессор` (или название видеокарты).
Должно закончиться строкой `Настройки в порядке.` Если пишет «нет файла модели» — раздел 2.

## 2. Модель (`models\best.pt`) — из GitHub Releases

Программе нужен файл обученной нейросети `models\best.pt` (~23 МБ). В git его нет — большие
файлы хранятся в разделе **Releases** репозитория на GitHub.

### Как получить модель

- **Автоматически:** если в `config.toml` заполнена ссылка `model.url`, программа сама
  скачает модель при первом запуске. Или заранее:
  ```powershell
  .venv\Scripts\python.exe download_model.py
  ```
- **Вручную:** открыть на GitHub страницу репозитория → **Releases** → скачать `best.pt` →
  положить в папку `machine_learning\models\`.

После скачивания программа сверяет **контрольную сумму** файла (`model.sha256` в `config.toml`):
так видно, что скачалась нужная версия модели, а не другая или испорченная.

### Как выложить модель (один раз на каждую версию модели)

1. На странице репозитория на GitHub: **Releases** → **Draft a new release**.
2. **Choose a tag** → написать, например, `model-v2` → **Create new tag**.
   Название: `Модель досок v2 (YOLO26s-seg)`. В описание можно вписать качество:
   `mAP50 маски 0.958, mAP50-95 0.666; sample.mp4: 17/17 досок, 978–1019 см`.
3. Перетащить файл `models\best.pt` в поле **Attach binaries** → **Publish release**.
4. В готовом релизе правой кнопкой по `best.pt` → **Копировать адрес ссылки**. Вида:
   `https://github.com/<владелец>/<репозиторий>/releases/download/model-v2/best.pt`
5. Вставить эту ссылку в `config.toml` → `[model]` → `url = "..."` и сохранить в git.

Если репозиторий **приватный**, автоматическое скачивание по ссылке не сработает
(GitHub требует вход) — тогда модель скачивается вручную со страницы Releases.

### Когда модель переобучили

Новая версия — новый релиз (`model-v3`) и две строки в `config.toml`:
- `url` — ссылка на новый файл;
- `sha256` — его контрольная сумма. Посчитать:
  ```powershell
  Get-FileHash models\best.pt -Algorithm SHA256
  ```

## 3. Запуск

```powershell
cd путь\к\проекту\machine_learning
.venv\Scripts\python.exe measure_boards.py путь\к\видео.mp4
```

Примеры:

```powershell
# тестовое видео, с видео-разметкой
.venv\Scripts\python.exe measure_boards.py data\sample.mp4

# часовое видео, только таблица (быстрее: не пишет видео)
.venv\Scripts\python.exe measure_boards.py data\raw\hiv00000.mp4 --no-video

# только кусок видео: с 60-й по 360-ю секунду
.venv\Scripts\python.exe measure_boards.py data\raw\hiv00000.mp4 --start 60 --end 360
```

Видео в git не хранятся (они большие). Тестовое `sample.mp4` (17 минут, 17 досок по 10 м,
256 МБ) и часовые записи передаются отдельно; удобно класть их в папку `data\`.

| Параметр | Что делает |
|---|---|
| `--no-video` | не записывать видео с разметкой (быстрее) |
| `--start 60` | начать с 60-й секунды видео |
| `--end 360` | закончить на 360-й секунде |
| `--out папка` | куда сохранить результаты (по умолчанию `results\<имя видео>\`) |
| `--device cpu` / `--device 0` | нейросеть на процессоре / на видеокарте NVIDIA (по умолчанию выбирает сама) |

Во время работы раз в минуту видео печатается ход:
```
  2:16.0  досок: 3, выбросов: 0  (9.6 кадров/с, x0.38 от реального времени)
```
`x0.38` — программа работает в 0.38 скорости видео (подробнее — раздел 7).

В конце:
```
Досок: 17, выбросов (≤ 900 см): 0, не измерено: 1
Таблица: ...\results\sample\boards.csv
Видео:   ...\results\sample\annotated.mp4
```

## 4. Результаты

Папка `results\<имя видео>\`:

### `boards.csv` — таблица досок (открывается в Excel)

| Столбец | Что значит |
|---|---|
| `номер` | номер доски по порядку |
| `появилась` | когда доску положили на конвейер (минуты:секунды видео) |
| `появилась_с` | то же в секундах |
| `длина_см` | измеренная длина; пусто — не измерена |
| `статус` | `норма`, `выброс`, `не измерена` или `не завершена (конец видео)` |
| `как_измерена` | способ измерения или причина, почему не измерена |
| `точек_торца` | сколько раз модель уверенно видела правый торец (чем больше, тем надёжнее; минимум 8) |
| `кадров_торец_и_сдвиг` | сколько кадров пошло в расчёт длины (минимум 3) |
| `скорость_см_с` | с какой скоростью станок тянул доску (обычно ~70 см/с) |

Статусы:
- **норма** — длина больше `N × (1 − погрешность)`, сейчас больше 900 см;
- **выброс** — длина 900 см и меньше;
- **не измерена** — доска посчитана, но длину честно измерить не удалось.
  Причина — в столбце `как_измерена`. Пример: `левый торец в покое уже в станке` —
  доску протолкнули в станок раньше, чем она успела полежать. Тогда неизвестно, где её левый конец.
- **не завершена (конец видео)** — видео закончилось, когда доска ещё не уехала.
  В итог не считается.

### `summary.json` — итог одной строкой для других программ

```json
{ "boards": 17, "outliers": 0, "not_measured": 1, "unfinished": 0, "lengths_cm": [null, 992.9, ...] }
```

Именно эти числа потом будет возвращать сервис (API) оркестратору.

### `annotated.mp4` — видео с разметкой

- **жёлтый контур** — текущая доска измеряется, **зелёный** — норма, **красный** — выброс;
- **тонкие контуры** — остальные ответы модели (зелёный — уверенный, серый — неуверенный);
- над доской — её номер и длина, сверху слева — счётчики.

Видео уменьшено в 2 раза. Записывается в формате, который открывается в обычном
проигрывателе Windows («Кино и ТВ») или в VLC.

## 5. Настройки — `config.toml`

| Настройка | Сейчас | Что значит |
|---|---|---|
| `marker.length_cm` | 100 | длина красного маркера, см (задаёт масштаб) |
| `boards.normal_length_cm` | 1000 | N — длина нормальной доски, см |
| `boards.tolerance_percent` | 10 | выброс, если короче N на столько процентов и более |
| `model.path` | `models/best.pt` | файл модели |
| `model.url` | пусто | откуда скачать модель (GitHub Releases), раздел 2 |
| `model.sha256` | длинная строка | контрольная сумма модели |
| `model.device` | `auto` | на чём считать нейросеть: `auto`, `cpu`, `0` (видеокарта) |
| `model.every_n_frames` | 5 | модель смотрит каждый 5-й кадр (5 раз в секунду) |
| `geometry.machine_entry_x/y` | 73 / 862 | где вход в станок на кадре (пиксели) |
| `geometry.length_correction_cm` | 0 | поправка, прибавляется к каждой длине |

Числа пишутся с точкой (`12.5`). Сохранили файл — изменения действуют со следующего запуска.

## 6. Как это работает

Камера — «рыбий глаз», кадр в ширину около 10.4 м. 10-метровая доска почти во весь кадр:
пока она лежит, её **левый конец у входа в станок, а правый — за краем кадра**.
Поэтому длину по одному кадру не измерить, и программа считает её в движении.

1. **Нейросеть** 5 раз в секунду находит доски — их контуры (`detector.py`).
2. **Новая доска** — длинный объект у входа в станок, который полторы секунды лежит
   неподвижно, причём прежняя доска уже поехала.
3. **Сдвиг D** — насколько доска уехала в станок с момента покоя. Считается в каждом кадре
   по рисунку древесины (сучки, волокна) в центре кадра, где «рыбий глаз» почти не искажает
   (`tracker.py`).
4. **Правый торец.** Когда торец доски проходит через центр кадра, модель уверенно его видит.
   По этим точкам строится прямая «положение торца от времени» (станок тянет ровно, ~70 см/с).
5. **Длина** = положение правого торца + сдвиг D − вход в станок (`measure.py`).
   Пиксели переводятся в сантиметры по модели объектива (`lens.py`, `calibration.json`).
6. Если доска так и не поехала в станок, это не доска: она не считается.

| Файл | Что внутри |
|---|---|
| `measure_boards.py` | главная программа: читает видео, считает доски, пишет результаты |
| `detector.py` | запуск нейросети и разбор её контуров |
| `tracker.py` | сдвиг доски по рисунку древесины |
| `measure.py` | прямая по правому торцу и расчёт длины |
| `lens.py`, `calibration.json` | модель объектива: пиксели → сантиметры |
| `settings.py`, `config.toml` | настройки |
| `download_model.py` | скачивание модели из GitHub Releases |

## 7. Проверка точности и скорость

**Точность** — на `sample.mp4`. По данным завода, там 17 досок по 10 м ± 15 см:

| | Результат |
|---|---|
| Досок найдено | 17 из 17 |
| Измерено | 16 (первую доску протолкнули в станок раньше, чем она легла, — «не измерена») |
| Длины | 978–1019 см, в среднем 1006 см (отклонение от 1000 не больше 2.2%) |
| Ложных выбросов | 0 (порог 900 см, самая короткая доска — 978 см) |
| Ложных досок на пустом конвейере | 0 (в видео ~11 минут без досок) |

Длины получены без подгонки под эталон: программа знает только длину маркера (1 м).
Для сравнения: классическая программа без нейросети (отдельный репозиторий `analization`) давала 899–987 см.

**Скорость** на этом компьютере — около 0.4 от реального времени: `sample.mp4` (17 минут)
обработан за 42 минуты вместе с видео-разметкой, час видео — примерно 2.5 часа. Больше всего времени уходит на
нейросеть (~0.25 с на кадр) и на распаковку видео (~20 мс на кадр). Флаг `--no-video` экономит
немного.

**На видеокарте NVIDIA** нейросеть считается в десятки раз быстрее, а распаковка видео
по-прежнему идёт на процессоре. Ожидается примерно реальное время или быстрее
(оценка; на RTX 5070 ещё не замерено). Ускорение для завода (OpenVINO для процессоров Intel,
аппаратная распаковка видео) — следующий этап.

## 8. Ограничения — что важно знать

- **Камера и конвейер должны быть те же.** Калибровка объектива и место входа в станок
  привязаны к этой камере. Если камеру сдвинут — нужна новая калибровка.
- **Часовые видео идут подряд.** Доска, которая лежит на стыке двух файлов, в первом файле
  будет «не завершена», а во втором может быть «не измерена». Учёт стыков — следующий этап.
- **Короткие доски на реальном видео ещё не проверены**: в `sample.mp4` все доски по 10 м.
  Программа рассчитана на доски 5–10 м. Короткую доску она меряет так же. Если её правый
  торец виден, пока доска лежит, длина берётся сразу.
- **Неуверенные ответы модели не используются.** На движущейся доске видеокодек оставляет
  «призрак» — бледный след. Модель иногда принимает его за доску, но с низкой
  уверенностью (< 0.65).

## 9. Если что-то не так

| Сообщение | Что делать |
|---|---|
| `нет файла модели models\best.pt` | скачать модель — раздел 2 |
| `...НО PyTorch не видит видеокарту` | установлен PyTorch для процессора — раздел 1, вариант Б |
| `скачался не тот файл (контрольная сумма ...)` | ссылка и `sha256` в `config.toml` от разных версий модели — раздел 2 |
| `не открылось видео` | проверить путь к файлу; путь с пробелами взять в кавычки |
| `ModuleNotFoundError` | окружение не установлено — раздел 1 |
| много «не измерена» | посмотреть `annotated.mp4`: видно ли доску, не закрывают ли её люди |
